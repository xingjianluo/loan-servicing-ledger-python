# 本地贷款服务与还款入账（loan-servicing-ledger）

面向**单个借款账户**的本地可运行贷款服务：摊还计划生成、还款入账分配、
逾期判定与罚息计提、账户状态迁移。全部数据存放在**进程内存或本地 JSON 文件**，
不依赖任何外部服务、数据库或真实凭据。

技术栈：Python 3.14 + FastAPI + pytest；金额一律使用 `Decimal`（按分量化），
禁止 `float` 参与金额运算。

## 目录结构

```
loan/
  money.py         金额/利率解析与分位量化
  models.py        领域模型：条款、分期、分配、凭证、事件、余额视图
  amortization.py  摊还计划：等额本息/等额本金、调息、提前还款重算
  account.py       账户聚合：逾期/罚息、状态迁移、入账分配、幂等
  storage.py       InMemoryStore 与 JsonFileStore（本地持久化）
  service.py       应用服务：账户级锁串行化 + 参数校验
  api.py           FastAPI HTTP 接口与稳定错误码
tests/             31 个用例（打印输入、关键中间状态、判定依据）
demo.py            端到端本地演示
main.py            HTTP 服务入口
```

## 一、摊还规则

- 首期到期日 = 放款日 +1 个整月；月末日期自动取目标月最后一天
  （如 3/31 +1 月 = 4/30）。
- **等额本息**：按 `PMT = P·r·(1+r)^n / ((1+r)^n − 1)` 计算年金月供，
  每期利息 = 期初剩余本金 × 月利率，本金 = 月供 − 利息。
- **等额本金**：每期本金 = 本金/期数（末段找平），利息 = 剩余本金 × 月利率，
  月供逐期递减。
- **尾差处理**：逐期金额四舍五入到分（`ROUND_HALF_UP`），舍入累计误差并入
  最后一期本金。因此：
  - 每期 `本金 + 利息 = 应还合计`（结构恒等）；
  - `Σ 各期本金 = 贷款本金`，不存在无法解释的尾差（测试逐条断言）。
- **期间利率调整**：按到期日归属，`due_date ≥ 生效日` 的期适用新利率。
  等额本息在利率段首期以"剩余本金/剩余期数/新月利率"重算年金月供；
  等额本金本金段不变，仅后续利息变化。调整请求中若生效日早于放款日、
  晚于末期到期日、同日重复调息，均被拒绝（`RateAdjustmentError`）。
- **提前还款重算**（须先无到期欠款）：
  - `KEEP_TERM`：期数与到期日不变，未来各段重算月供；
  - `KEEP_PAYMENT`：沿用原月供/本金段，期数自然缩短，末期以剩余本金找平；
  - 已发生期（含已还/计提数据）原样保留，未来期本金之和
    恰好 = 提前还款时点未到期本金 − 提前还款额。
  - 提前还款额超过未到期本金会被拒绝。

## 二、还款入账与资金分配

- 只偿还**已到期**部分；允许部分还款。
- 资金按稳定的桶优先级依次填满，默认：
  **利息 → 罚息 → 费用 → 本金**（`allocation_order` 可配置为四桶的任意排列），
  同一桶内按期数从小到大。
- 分配结果守恒：四桶分配之和严格等于还款金额。
- 超过截至还款日"到期应还合计"的还款被拒绝（`PaymentExceedsDueError`，
  响应中带 `allowed` 可还上限）；未到期提前还本请走提前还款接口。
- **幂等**：`payment_id` 为幂等键。
  - 同键同参重复/并发提交：返回原凭证，余额只扣减一次；
  - 同键不同参：返回冲突错误 `DuplicatePaymentError`，不静默覆盖。
- 并发控制：每个账户一把可重入锁，同一账户写请求在服务层串行化，
  不同账户互不阻塞；账户内再有 `RLock` 保护"检查—扣减"全过程。

## 三、逾期、罚息与状态迁移

- 每期 `due_date` 为应还日；宽限期 `grace_period_days` 内未足额仍属正常，
  自 `overdue_start = due_date + 宽限天数 + 1` 当日起进入逾期。
- **罚息**：基数为该期"当日未还本金"，`罚息 = 基数 × 日罚息率 × 自然日天数`。
  罚息不是扫描时累积的数字，而是依据**本金偿还历史对任意日期确定性重算**，
  因此：
  - 余额只是"日期 + 还款历史"的纯函数，与扫描/查询的次数和时机无关
    （天天扫描和直接跳到远期查询结果一致，测试有对拍用例）；
  - 部分还本后次日起基数自动下降，已计部分不回退；还款日当天仍按还款前
    基数计息（与"还款清偿含当日罚息"自洽）；
  - 分段利息高精度求和后一次性量化到分，避免分段舍入尾差。
- **逾期管理费**：每期首次进入逾期时按逾期起始日未还本金 × `fee_rate`
  一次性计提，同一期不重复。
- **账户状态**：
  - `ACTIVE` 正常（含宽限期内）；
  - 任一已过宽限期的期本金/利息未足额 → `OVERDUE`；
  - 逾期欠款（含罚息、费用）补齐且未再有逾期期 → 回到 `ACTIVE`；
  - 全部款项为零 → `SETTLED`，此后任何普通还款/提前还款均被拒绝
    （`AccountClosedError`）。
- 每次状态迁移、费用/罚息计提、还款、调息、提前还款都落**带序号的事件流**
  （`GET /accounts/{id}/events`），可追溯。

## 四、可配置项

| 配置 | 含义 | 默认 |
| --- | --- | --- |
| `principal` | 贷款本金（>0，精确到分） | 必填 |
| `annual_rate` | 年利率，如 `0.072` | 必填，可后续调整 |
| `term_months` | 期数（月） | 必填 |
| `origination_date` | 放款日 | 必填 |
| `amortization_type` | `equal_installment` / `equal_principal` | 等额本息 |
| `grace_period_days` | 宽限期自然日数 | `0` |
| `penalty_daily_rate` | 日罚息率（允许高精度，如 `0.0005`） | `0` |
| `fee_rate` | 每期逾期管理费比例（一次性） | `0` |
| `allocation_order` | 还款桶优先级（四桶排列） | 利息→罚息→费用→本金 |
| 存储 | `InMemoryStore` / `JsonFileStore(path)` | 内存 |

## 五、失败原因对照（HTTP 错误码）

| 场景 | 异常 / error_code | HTTP |
| --- | --- | --- |
| 零/负/非数字/超精度金额、float 入参 | `INVALID_AMOUNT` | 400 |
| 条款非法、提前还款超本金等 | `INVALID_SCHEDULE` | 400 |
| 调息日非法/同日重复/无受影响期 | `RATE_ADJUSTMENT_REJECTED` | 400 |
| 还款超过到期应还 | `PAYMENT_EXCEEDS_DUE`（带 `allowed`） | 422 |
| 同 payment_id 参数冲突 | `DUPLICATE_PAYMENT_CONFLICT` | 409 |
| 有到期欠款却申请提前还款等 | `ACCOUNT_STATE_CONFLICT` | 409 |
| 已结清账户再次入账 | `ACCOUNT_CLOSED` | 409 |
| 账户不存在 | `ACCOUNT_NOT_FOUND` | 404 |

## 六、本地验证方法

```bash
# 1) 安装依赖（uv 会自动创建 .venv）
uv sync

# 2) 跑全部测试（用例打印输入、关键中间状态与判定依据）
uv run pytest -s

# 3) 端到端脚本演示（逾期/部分还款/并发幂等/调息/提前还款/事件流）
uv run python demo.py

# 4) 启动本地 HTTP 服务（无任何外部依赖）
uv run python main.py
# 打开 http://127.0.0.1:8000/docs 手工调用，或：
curl -s -X POST http://127.0.0.1:8000/accounts -H 'Content-Type: application/json' -d '{
  "account_id":"A1","principal":"120000.00","annual_rate":"0.072",
  "term_months":12,"origination_date":"2026-01-01",
  "grace_period_days":3,"penalty_daily_rate":"0.0005","fee_rate":"0.01"}'
curl -s 'http://127.0.0.1:8000/accounts/A1/balance?as_of=2026-02-08'
```

需要重启后保留数据时，把存储换成 `JsonFileStore("ledger.json")`
传入 `create_app(LoanService(JsonFileStore(...)))`；幂等键与余额随文件一起恢复。

### 测试覆盖场景

- 摊还守恒：两种口径、零利率/1 分本金/360 期等边界形态、月末日期、
  期间调息、两种提前还款重算；
- 还款：部分还款及自定义分配顺序、重复提交、8 线程并发同键、
  10 线程并发异键、超额/非法金额/已结清拒绝；
- 逾期：宽限期内不逾期、跨宽限期首日逾期、增量罚息、
  罚息路径无关性（扫描时机对拍）、部分还本后分段计息、补齐回 ACTIVE、
  全部结清 SETTLED 且资金守恒；
- 调息与提前还款经服务层重算后的守恒；
- JSON 持久化重载后幂等仍然生效；
- HTTP 层各失败原因返回可区分的稳定错误码。
