# 贷款服务与还款入账（本地可运行）

面向**单个借款账户**的本地贷款账本：生成摊还计划、还款入账（含幂等）、
逾期判定与状态迁移。纯内存实现，无外部服务、无真实凭据。金额一律使用
**整数“分”**，利息计算使用 `Decimal` + `ROUND_HALF_UP`，杜绝浮点尾差。

## 运行环境

- Python 3.14+，依赖管理使用 [uv](https://docs.astral.sh/uv/)
- 安装：`uv sync`
- 测试（带输入/中间状态/判定依据打印）：`uv run pytest -s`
- 启动本地 API：`uv run python main.py`，随后访问 <http://127.0.0.1:8000/docs>

## 摊还规则

- 按月还款，月利率 = 年利率 / 12，首期到期日为起借日后一个月（月末自动对齐）。
- **等额本息**：月供 = P·r·(1+r)ⁿ / ((1+r)ⁿ − 1)，先四舍五入到分；
  每期利息 = 上期剩余本金 × 月利率（四舍五入到分），当期本金 = 月供 − 利息；
  **末期本金兜底**为剩余本金，吸收全部累计舍入。
- **等额本金**：每期本金 = P / n（整除基数），**末期吸收本金尾差**；
  每期利息 = 剩余本金 × 月利率。
- 零利率、奇数本金（强制制造尾差）均为支持边界。
- **守恒约束（测试强制校验）**：
  - 每期 本金 + 利息 = 本期应还总额；
  - 累计本金严格等于贷款本金，不存在无法解释的尾差；
  - 等额本息末期月供与平均月供的偏差 ≤ 期数/2 分（每期 ≤0.5 分的舍入累积上界）。

### 利率调整与提前还款后的重算

- **期间利率调整**：仅重算“未到期且完全未还”的期次；已部分还款的当期
  保持原金额（历史已发生的债权债务不追溯修改）。重算后未来期本金合计
  不变，利息随利率变化。
- **提前还款**：超过当前已到期应还的资金视为提前还款，采用**余额法**——
  直接冲减剩余本金余额，未来各期按原期数、原到期日重新摊还（月供下降）。
  若资金足以覆盖全部剩余本金与利息，则按 FIFO 完成提前结清。
- 重算作用域之外期次的未还本金不参与分摊，因此重算后
  “各期未还本金合计 = 账户剩余本金”恒成立。

## 还款分配规则

入账资金按以下**固定优先级**依次分配（稳定、可预测）：

1. **罚息**
2. **费用**
3. **已到期利息**（到期日 ≤ 还款日，按期号 FIFO）
4. **已到期本金**（同上，按期号 FIFO）
5. **提前还本金**（见上文“余额法”；提前结清时再冲未到期利息）

分配恒等式：`罚息 + 费用 + 利息 + 本金 = 还款金额`。支持任意金额的部分还款。

## 幂等与并发

- 每笔还款必须携带非空 `request_id`；同一 `request_id` 的重复提交直接
  返回**首次回执**（回执标记 `duplicate=true`），账户余额不重复扣减。
- 账户内部使用线程锁串行化写入；并发提交相同 `request_id` 时仅首笔真正
  入账，其余全部幂等重放；并发不同请求串行执行，入账总额不重不漏。

## 逾期判定与状态迁移

- 期次状态：`PENDING`（未到期）→ `GRACE`（到期日至到期日+宽限期内）
  → `OVERDUE`（超过宽限期仍未足额）→ `PAID`（足额后任意时点）。
- 账户状态：`ACTIVE` / `OVERDUE` / `SETTLED`；
  - 宽限期内足额还款：不产生罚息，账户保持正常；
  - 宽限期后仍欠：进入 `OVERDUE`，按日计提罚息，
    **逐天**对“当日已过宽限期的未还金额 × 日罚息率”计息（跨宽限期、
    部分还款后基数下降均可正确处理）；
  - 欠款补足（含罚息、费用）后恢复 `ACTIVE`；全部科目结清为 `SETTLED`。
- 每次账户状态迁移都记录 `StatusChange(日期, 原状态, 新状态, 原因)`，可追溯。

## 可配置项（LoanConfig）

| 配置 | 含义 | 默认/示例 |
| --- | --- | --- |
| `principal_cents` | 贷款本金（分，正整数） | `1_000_000_00`（100 万元） |
| `annual_rate` | 年利率（小数，≥0） | `0.036` |
| `periods` | 期数（月） | `12` |
| `method` | `EQUAL_INSTALLMENT` 等额本息 / `EQUAL_PRINCIPAL` 等额本金 | — |
| `start_date` | 起借日（首期到期日 = 次月同日，月末对齐） | — |
| `grace_days` | 宽限期天数 | `3` |
| `penalty_daily_rate` | 逾期罚息日利率 | `0.0005`（万分之五） |

## 失败原因区分（errors.py）

| 异常 | HTTP 状态码 | 触发场景 |
| --- | --- | --- |
| `InvalidAmountError` | 400 | 金额为 0、负数或非整数 |
| `InvalidRequestError` | 400 | `request_id` 为空、利率为负、本金/期数非法 |
| `ExcessPaymentError` | 422 | 还款金额超出当前全部应还（本金+利息+罚息+费用） |
| `AccountSettledError` | 409 | 已结清账户再次入账 |

## 本地 HTTP API（main.py）

| 方法/路径 | 说明 |
| --- | --- |
| `GET /schedule` | 当前摊还计划（含每期已还/状态） |
| `GET /balances` | 各科目未还余额（penalty/fee/interest/principal） |
| `GET /status?as_of=YYYY-MM-DD` | 推进到指定日期的逾期判定与状态迁移历史 |
| `POST /payments` | `{request_id, amount_cents, pay_date}` 还款入账 |
| `POST /rate-adjustments` | `{new_annual_rate, effective_date}` 利率调整 |
| `POST /fees` | `{amount_cents}` 计收一笔费用 |

示例（服务启动后）：

```bash
curl -X POST localhost:8000/payments -H 'Content-Type: application/json' \
  -d '{"request_id":"demo-1","amount_cents":8496726,"pay_date":"2026-02-01"}'
curl -X POST localhost:8000/payments -H 'Content-Type: application/json' \
  -d '{"request_id":"demo-1","amount_cents":8496726,"pay_date":"2026-02-01"}'
# 第二次返回 duplicate=true，余额不变
```
